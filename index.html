Custom Wordle (Dictionary-powered)

🎯 Project Overview

A browser-based Wordle clone that uses curated dictionaries for valid guesses and daily targets. Built to explore word lists, input validation, and clear feedback UX.

🧰 Technologies Used

HTML, CSS, JavaScript. Word lists (JSON), state management, localStorage for streaks.

🔑 Key Learnings

Dictionary lookups and performance, keyboard UX, accessibility for color feedback, and clean component-like JS without frameworks.

🚀 Future Development

Daily puzzle seed, hard mode, statistics dashboard, shareable results, and mobile-first keyboard.
